Prompt mới — nhờ chatbot tóm cuộc trò chuyện

  1. Làm xong một việc hay trong một chat với Claude (hoặc chatbot khác).
  2. Bấm Sao chép bên dưới, dán vào chính chat đó, gửi đi. Chatbot sẽ tóm tắt, lọc ra phần cuối cùng đã chốt và điền đúng khung M5 Prompt Kit.
  3. Chatbot xuất một file .md — tải file đó về máy.
  4. Bấm Tải file lên (hoặc kéo thả file vào trang). Trang tự soát: đúng khung mới cho lưu, sai thì báo từng chỗ để anh nhờ chatbot sửa.
